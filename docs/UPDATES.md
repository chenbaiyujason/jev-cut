# 最新功能与行为变化

本页对应 2026-09-27 晚间源码快照，具体来源见 `release-manifest.json`。已有演示视频展示的是录制时版本，新功能以当前源码和说明为准。

## jev 单镜匹配

- 从时间轴工具栏拖入“jev匹配”，或点击后在播放头插入占位节点；需要主音乐覆盖该位置。
- 占位节点可以调整最大时长，右侧面板支持填写局部意图。留空时使用全片目标与前后文。
- 从全库召回，由 jev 比较镜头、实际源窗口和拍点附近的结束位置。
- 回填限于占位范围，不向后挤动已有镜头；多余空间可继续放入新的占位节点。
- 保留工程版本校验、锁定保护、可撤销操作、可选视觉复核和输入输出记录。

## 广候选快速选镜

策略版本为 `jev-wide-fast-v2`。候选通过执行与明确叙事约束后全部进入模型，不再按 RAG 排名截为16个。模型为每个候选做独立基础适配评分，共享主题和乐段上下文；按 token 预算拆请求，不丢候选。

缓存只保存稳定的基础适配，不缓存“下一镜选谁”。最终选择每次读取当前前后镜、重音、原帧使用信息和实际裁剪窗口；不再附加一轮未用于执行的逐窗口评分。详见 [候选与缓存策略](SELECTION.md)。

## 续剪与规划复用

“补齐后续”只规划主音轨新增的尾段，并携带已有画面的衔接信息。已有规划以源音频时间保存，在音乐理解、目标、速度等条件一致且覆盖目标区间时复用；不缓存一个项目永久可用的素材白名单。

生成准备阶段即可显示待填充位置，真实镜头逐个提交。停止生成保留已经排入的部分。

## 停顿后的重音与动作时序

音乐停顿后的重新进入被独立标记为结构性重音，避免被普通主重音的间距筛选挤掉。该信息映射到裁剪、变速后的实际时间轴，并参与切点与动作释放位置的选择。

自动表达默认策略为 `action-timing-v1`：启用受约束的动作时序与分段变速；额外表现转场默认关闭。网页渐进流程已接入准备就绪的结构性重音处理，但这不等于任意连续变速曲线或所有导演手法都已完成。

## 防重复与叙事约束

默认替换名单排除未标记重复意图的已用镜头，实际窗口编译另检查源帧重叠。连续动作通过紧接原出点的新帧续接；有意重复需明确标记，不能把原帧倒带伪装成动作继续。

后端还提供可选角色阶段约束，以及一个特定角色的阶段与排序实现。这是依赖素材注释的实验接口，不是输入任意角色名就能自动获得完整成长线的通用功能。
