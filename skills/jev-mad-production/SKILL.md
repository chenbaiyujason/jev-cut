# 从视频到可编辑漫剪

先定位包含 `apps/backend`、`apps/editor` 和 `tools/media-pipeline.mjs` 的 jev剪辑仓库根目录。复用已有清单和缓存；当前任务的主角、音乐、长度与范围优先，不把开发案例中的角色或11集限制带进新项目。

## 1. 把来源落到可验证的本地素材

- 用户只有视频网址时，用当前可用的下载工具/网站下载入口取得真实视频；已有OpenCLI时可复用，不将某个个人登录环境作为本Skill前提。
- 用ffprobe确认实际视频流、音轨、时长、帧率；不要把封面、预览图或只有音频的下载当成原视频。
- 为文件记录来源URL、文件哈希、版本/集数、字幕来源和语言。影视媒体、字幕、音乐都放在被忽略的`data/`或外部素材目录，不提交到源码仓库。
- 字幕必须对应同一剪辑版本。抽查开头、中段、末尾台词对齐；存在整体偏移先修正，不能用错误字幕强化语义判断。

## 2. 写显式素材清单

参考仓库的 `examples/sources.example.json`，保存到 `data/sources.json`。视频编号必须唯一；路径相对于清单目录；`subtitle`可省略，优先同源内嵌字幕，缺失时明确记录。

```sh
npm run media -- --manifest data/sources.json --stage local --dry-run
npm run media -- --manifest data/sources.json --stage local
```

若依赖未安装，先按仓库 `docs/SETUP.md` 安装FFmpeg、媒体Python环境和TransNetV2权重。不要把本机Python绝对路径写进可发布文件。

## 3. 检查镜头与代理，之后再做理解

使用TransNetV2按原始帧序列检测，保留PTS与源帧率。模型输入的48×27尺寸只用于切镜，不表示按低fps跳过镜头。VFR需先建立正确的时间映射或显式规范化，不能直接拿帧号除假定fps。

播放器代理保留原时序；模型分析代理可降至约640宽、12fps、CRF/CQ30、单声道64kbps。三帧证据必须在镜头内部；短镜头尤其要检查残余切镜、黑白空帧、主体出画与错误OP/ED。不要用固定秒数粗切代替镜头检测。

确认代理可播放、字幕对齐和镜头抽样正确后：

```sh
npm run media -- --stage understand
npm run media -- --stage embedding
npm run media -- --stage index
```

理解模型读取压缩视频和实际原声，并结合字幕记录人物、动作阶段、情绪、方向、台词含义、声音事件与不确定性。模型服务及Key由使用者配置；缺配置时只询问服务/模型与本机配置位置，不要求在对话里贴Key。

重跑时利用阶段缓存。错误ID、越界动作峰值不能作为卡点；低动作量并不自动等于无价值镜头，不能把眼神或有意义的静止演出从全库删除。

相同编号换了视频版本时不要复用旧缓存；使用新编号或明确重建该项。字幕、字幕偏移或理解参数改变后，同样需要核对并重建受影响阶段，不能只看“文件已存在”。

## 4. 以音乐和目标开始剪辑

先理解音乐实际结构，再规划乐句与叙事职责。主角、情绪、时长来自本次用户输入；不要求用户手写完整分镜。区分听到的音乐事实与创作联想，不猜听不清的歌词。

模型规划给出段落目标，jev决策按当前音乐位置和时间轴上下文选择实际素材。每次决策都应允许重新查询全库，而不是把上一轮小候选集当作素材总集。检索相似度只作证据，不能代替实际选镜。

素材插入还要决定：是否保留原声、是否需要重音、如何接下一镜、是否调色。保持现状也是合法选择。原声轨若仍含原片配乐，不能标成纯人声；对白应完整，必要时让配乐让位。

## 5. 在用户授权范围内修改

从当前时间轴获取选中片段与入出点；按明确范围执行，不能在未选择时静默修改全片。保留范围外、未选中间隙、锁定内容与被保护的完整台词。

项目帧与源帧率分开计算。转场隐藏余量不得跨越原片切镜；边界拆分不能因取整改变范围外画面。提交使用baseRevision，取消/新请求使旧结果失效，不覆盖更晚的用户编辑。

## 6. 验证与交付

实际播放或导出检查：首个节奏释放、人物身份、视线/动作衔接、有意重复与误重复、原声可听度、字幕对应、黑屏/停格。参考图和模型审片是辅助，不替代看听。

保留真实请求、完整候选、选择结果、合法性校验及耗时；不补写模型未输出的内部思考。计时分开列出音乐理解、规划、召回、决策、时间轴应用、首帧与导出；缓存命中不冒称冷启动性能。

交付可播放成片、可编辑时间轴和可读决策记录。公开源码只保留可再分发的示例，不附带用户的原片、字幕、密钥、权重或私人索引。
